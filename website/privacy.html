Privacy Policy

TimerLock is designed as an offline Android utility. The current Android build does not request Internet access and does not include advertising or analytics SDKs.

Website analytics

The TimerLock website uses Vercel Web Analytics for aggregate website traffic measurement where supported by the active hosting plan and configuration. The website may also record aggregate interaction events, such as APK-download or donation-button clicks, when that analytics capability is available. Actual APK download totals are independently provided by GitHub Releases. Website analytics is separate from the Android app.

Android permissions

Display over other apps: used only by TimerLock to show the floating countdown.

Device Admin: used to request Android system screen lock at expiry.

Notifications / foreground service: used for visible active-timer operation.

Alarms & reminders: used for expiry scheduling.
