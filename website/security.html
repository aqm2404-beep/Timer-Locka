TimerLock system access

Floating overlay

Display over other apps is granted to TimerLock itself once.

Device Admin

Used to request Android system screen lock when the countdown reaches zero.

How to uninstall

  1. Open Android Settings.
  2. Open Security / Security & privacy.
  3. Open Device admin apps.
  4. Deactivate TimerLock Device Admin.
  5. Return to Apps → TimerLock and uninstall.
