Cara install & penggunaan

A. Cara install

  1. Download APK.
    Download TimerLock-v4.3.0.apk terus dari GitHub.
  2. Jika Android blok pemasangan.
    Buka Settings → Privacy protection / Additional settings → Special permissions / Special app access → Install unknown apps. Pilih browser atau File Manager yang anda guna untuk membuka APK, kemudian aktifkan Allow from this source.
  3. Buka TimerLock.
    Cipta Admin password.
  4. Aktifkan permission.
    Benarkan Alarms & reminders, Notifications, Display over other apps untuk TimerLock sahaja, dan aktifkan Device Admin.
  5. Pastikan telefon ada PIN / pattern / password.
    Ini memastikan screen lock Android benar-benar memerlukan pengesahan.
Penting: “Install unknown apps” diberikan kepada aplikasi yang memasang APK seperti Chrome/File Manager. “Display over other apps” pula diberikan kepada TimerLock sahaja. Dua permission ini berbeza.

B. Cara penggunaan

  1. Tetapkan Hours, Minutes dan Seconds.
  2. Tekan START TIMER dan sahkan.
  3. Tekan Home atau buka aplikasi lain. Timer terus berjalan.
  4. Floating bubble menunjukkan baki masa, boleh dialih dan snap ke tepi skrin.
  5. Pada 00:00, TimerLock meminta Android system screen lock melalui Device Admin.
  6. Admin control kekal dilindungi password.

Xiaomi / HyperOS

Jika background app disekat, aktifkan Background autostart untuk TimerLock dan tetapkan Battery saver kepada No restrictions.
