TimerLock

A countdown that stays committed.

Set the timer, keep using your phone, and watch the remaining time in a draggable floating bubble. At 00:00, TimerLock requests the Android system screen lock.

Free · No ads · No account · Works offline

If download works but Android blocks installation: allow the browser or File Manager you used to download the APK under Install unknown apps. On Xiaomi/HyperOS this is typically Settings → Privacy protection / Additional settings → Special permissions / Special app access → Install unknown apps.
Installation

Install in a few steps

1

Download APK

Tap Download APK v4.3.0. The file name should be TimerLock-v4.3.0.apk.

2

Allow APK installation

If Android blocks it, enable “Allow from this source” for the browser or File Manager that opens the APK.

3

Complete TimerLock setup

Create Admin password, enable Alarms & reminders, Notifications, Display over other apps for TimerLock, and Device Admin.

Overlay permission: enable “Display over other apps” for TimerLock only once. You do not need to enable anything for WhatsApp, Chrome, YouTube, Facebook, or other apps.
Usage

Set it. Minimize it. Let it run.

1

Set the duration

Enter Hours, Minutes and Seconds, then tap START TIMER.

2

Use your phone normally

Press Home or open another app. The circular countdown bubble stays on top and can be dragged to the screen edge.

3

At 00:00

TimerLock confirms expiry and requests Android screen lock through Device Admin.
