# TimerLock Privacy Policy

Effective date: 13 September 2026

TimerLock is designed to operate locally on the user's Android device.

## Information collected
TimerLock does not collect personal information and does not transmit user information to the developer or to third parties.

## Internet access
TimerLock does not request Android's INTERNET permission and does not use analytics, advertising, tracking SDKs, cloud storage, or remote user accounts.

## Information stored locally
To provide its timer and security functions, TimerLock stores limited information only on the device, including:
- countdown and timer state
- TimerLock settings
- a salted hash of the TimerLock administrator password
- local TimerLock event and security logs

This information remains on the user's device unless the user independently copies or backs up device data using operating-system or third-party tools.

## Device Admin access
TimerLock may ask the user to activate Android Device Admin access. This access is used for the screen-lock function when the countdown expires or when the administrator manually tests the lock function. Activation is performed through Android's own Device Admin confirmation screen.

TimerLock does not use Device Admin access to read personal files, messages, contacts, photos, location, or other private content.

## Android device credentials
TimerLock does not read, store, or know the user's Android PIN, password, pattern, fingerprint, or other Android lock-screen credential.

## Children
TimerLock is a general-purpose utility and is not specifically directed at children.

## Changes
This privacy policy may be updated when TimerLock functionality changes. The effective date above will be updated when material changes are made.

## Contact
The developer support email and seller contact information are provided on the TimerLock Galaxy Store product page.
